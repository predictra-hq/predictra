| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Registrazione non autorizzata      | Signup pubblico disattivato. Ruoli assegnati solo tramite invito valido (`accept_invitation`)                                                                                         | Supabase Auth, `supabase/migrations/…_identity.sql` |
| Accesso ai dati altrui (IDOR)      | RLS su tutte le tabelle; testata in CI                                                                                                                                                | migrazione + `supabase/tests/identity.test.ts`      |

| Escalation di privilegi            | Ruoli e stato modificabili solo da RPC `SECURITY DEFINER` con controllo di gerarchia; Admin → solo USER; almeno un Super Admin attivo                                                 | migrazione, `packages/shared-types`                 |
| Azioni admin senza 2FA             | Le RPC amministrative richiedono `aal2` nel JWT; la UI blocca l'area admin senza 2FA                                                                                                  | `assert_admin_session`, `requirePermission`         |
| Brute force login / recupero / 2FA | Rate limit persistente per IP e per email (hash), fail-closed, più i limiti nativi di Supabase Auth                                                                                   | `lib/rate-limit.ts`, `consume_rate_limit`           |
| Enumerazione account               | Messaggi identici per credenziali errate ed email inesistenti nel recupero                                                                                                            | azioni login e forgot-password                      |
| Sessioni                           | Cookie gestiti da `@supabase/ssr`; JWT verificato con `getClaims()`; logout solo via POST; "esci dagli altri dispositivi"; dopo reset o cambio password chiusura delle altre sessioni | `proxy.ts`, `lib/auth/dal.ts`                       |
| Account sospeso                    | Stato `SUSPENDED` (RLS lo esclude da ogni dato) più ban in Supabase Auth (blocca login e refresh)                                                                                     | `set_account_status`, `admin/users/actions.ts`      |
| CSRF                               | Server Actions con controllo d'origine di Next.js; route di logout con controllo `Origin`; `form-action 'self'`                                                                       | Next.js, `auth/signout/route.ts`                    |
| XSS                                | Escaping di React; CSP restrittiva (`object-src 'none'`, `frame-ancestors 'none'`); nessun `dangerouslySetInnerHTML`                                                                  | `next.config.ts`                                    |
| SQL injection                      | Solo query parametrizzate (PostgREST, RPC con parametri tipizzati)                                                                                                                    | —                                                   |
| Open redirect                      | `safeNextPath` accetta solo percorsi interni (testato)                                                                                                                                | `lib/validation.ts`                                 |
| Segreti                            | `.env*` ignorati; chiave segreta solo nei moduli `server-only`; gitleaks in CI                                                                                                        | `.gitignore`, `lib/env.server.ts`, CI               |
| Indicizzazione                     | `robots.txt` disallow, `X-Robots-Tag: noindex`, meta robots                                                                                                                           | `robots.ts`, `next.config.ts`                       |
| Audit                              | `audit_logs` append-only (trigger blocca UPDATE, DELETE e TRUNCATE)                                                                                                                   | migrazione                                          |

## Limitazioni note (da chiudere in Milestone 8)

- La CSP usa `'unsafe-inline'` per gli script (necessario senza nonce). Hardening previsto con nonce generati nel proxy.
- La protezione da password compromesse di Supabase potrebbe non essere disponibile sul piano Free (**NON VERIFICATO**).
- Non c'è re-autenticazione con password per le azioni admin: è richiesta la sessione 2FA (`aal2`). Valutare la step-up con un nuovo codice TOTP per le azioni più distruttive.
- La pagina audit mostra le ultime 200 voci, senza filtri né paginazione.
- Un test end-to-end contro un Supabase reale (Auth + email) non è automatizzato. Va fatta la checklist manuale in `setup.md`.
